# Hyprland setup

## Hyprland
Copy the config file `hyprland.conf` and it should work

## Hyprpaper - wallpaper
You need to copy config `hyprpaper.conf` as well as `reload-wallpaper.sh` script


## Waybar - status bar
https://github.com/elifouts/Dotfiles

Copy config file, install pywal.

Make sure you have this in `hyprland.conf`
```
layerrule = blur, waybar
layerrule = ignorezero, waybar
layerrule = ignorealpha 0.5, waybar
```
